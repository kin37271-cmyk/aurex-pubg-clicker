# 🎮 Aurex PUBG Clicker Telegram Bot

Telegram foydalanuvchilari uchun **Aurex PUBG** uslubidagi to'liq va mukammal Clicker boti.

## 🌟 Imkoniyatlar

- 🎮 **Clicker & Energiya:**
  - Inline tugma va Web App orqali tanga yig'ish.
  - 100 ta boshlang'ich limit va avtomatik quvvat to'lishi.
- ⚡️ **Upgrade / Kuchaytirish Do'koni:**
  - **Multitap:** 1 bosishda olinadigan tangalarni oshirish.
  - **Max Limit:** Energiya limitini oshirish.
  - **Tezkor Quvvat:** Energiyaning to'lish tezligini tezlashtirish.
  - **Auto-Bot:** Passiv daromad (har soatda tangalar yig'ib berish).
- 💳 **Pul & PUBG UC Yechib Olish:**
  - Bank kartasiga so'm yechish.
  - PUBG Mobile hisobiga UC yechish.
- 📢 **Majburiy Obuna Kanallari**
- 👑 **To'liq Admin Panel**
